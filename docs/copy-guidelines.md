# Copy Guidelines (EN)

## 1) Positioning Line (Site-wide)
Primary
- Rare Earth Sentinel: From Evidence to Action

Alternative
- Rare earth risk intelligence for investors, industry, and policy

Notes
- Emphasize evidence to action, avoid any guaranteed returns language.
- No promises on outcomes.

## 2) Value Proposition (3 pillars)
1) Structured Evidence: Extract key signals from global sources
2) Actionable Guidance: Provide decision-grade recommendations
3) Continuous Monitoring: Track priority topics and alert on changes

Writing rules
- Avoid guaranteed profit or certain returns
- Use evidence, risk, path, monitoring, alert, action

## 3) CTA Templates (Unified)

### A) Report CTAs
- Primary CTA: Unlock Deep Report
- Secondary CTA: View Report Summary

Trigger
- Report card -> /en/pay/<report_id>.html

### B) Task CTAs
- Primary CTA: Sentinel executes recommendations
- Helper text (small/gray): Sentinel will continuously monitor and alert based on the recommendation.

Trigger
- Only show when recommendations exist
- Link -> /en/task/pay/<report_id>.html

## 4) Homepage Copy Structure (Recommended)

Hero
- Title: Rare Earth Sentinel: From Evidence to Action
- Subtitle: Risk intelligence for investors, industry, and policy
- Primary CTA: Unlock Deep Report
- Secondary CTA: Sentinel executes recommendations

Core Value (3 columns)
- Structured Evidence
- Actionable Guidance
- Continuous Monitoring

Trust/Methodology Block
- Sources, evidence chain, and structured workflow
- Build trust, no outcome promises

## 5) Pay Page Copy (Report / Task)

Report Pay Page
- Title: Deep Report | <Report Title>
- Value line: Structured evidence + action guidance + risk paths
- CTA: I have paid

Task Pay Page
- Title: Task Execution | <Report Title>
- Value line: Continuous monitoring + alerts + evidence-driven
- CTA: I have paid

Notes
- Payment memo must include order_id + email
- Avoid any claims of guaranteed outcomes

## 6) Tone and Forbidden Phrases
Tone: professional, evidence-driven, analytical
Avoid: guaranteed profit, certain returns, risk-free
Use: evidence, risk, path, monitoring, alert, actionable
